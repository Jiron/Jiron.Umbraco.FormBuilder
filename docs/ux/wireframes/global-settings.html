Malware scanner
None installed, so files aren't checked for malware. Learn more about file scanners
Stored in
A private folder outside the website: JironFormBuilder:Files:Root. Files have no public address; users download them from their entry.

Webhooks

Hosts that webhooks may call crm.example.com, events.nordwind.example JSON option lists use the same hosts. Host configuration sets them: JironFormBuilder:Webhooks:AllowedHosts.

Slack and Microsoft Teams

Slack and Microsoft Teams actions use these unless they set their own. The addresses work like passwords, so they are entered as references to host configuration.
