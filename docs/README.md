# Jiron Form Builder documentation

Jiron Form Builder is a form builder for Umbraco 17: editors design forms in the **Form Builder** section of the
backoffice, visitors fill them in on the website, and the site's team works with the entries that arrive.

## Start here

- [Getting started](getting-started.md): from installing the package to the first entry, in about ten minutes.
- [Installation](installation.md): requirements, the packages, what installing adds, and the few things a site sets up.

- [Field types](field-types.md): every field, its settings and what it stores.
- [Rules and validation](rules-and-validation.md): showing, hiding and requiring things, and checking answers.
- [Merge tags](merge-tags.md): answers and other values in emails, messages, redirects and defaults.

- [Entries and exports](entries-and-exports.md): the Inbox, approving, spam, notes and exports.
- [Insights](insights.md): how a form is doing.
- [Themes](themes.md): how forms look on the website, and the theme editor.
