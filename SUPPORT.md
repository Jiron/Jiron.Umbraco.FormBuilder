# Getting help

Jiron Form Builder is free to use and maintained by one person in their own time. There is **no guaranteed
support**, no response time and no service level, but questions and reports are welcome and read.

## Where to ask

- **Questions and ideas:** [GitHub Discussions](https://github.com/Jiron/Jiron.Umbraco.FormBuilder/discussions) on
  this repository.
- **Bugs:** a GitHub issue, using the bug report form.
- **Feature requests:** a GitHub issue, using the feature request form.
- **Security problems:** never in public; see [SECURITY.md](SECURITY.md).

## What to include

A report that can be reproduced gets fixed much sooner. Please include:

- the versions: Jiron Form Builder, Umbraco, .NET, and the database (SQLite or SQL Server);
- how the site is hosted (one server or several, Windows or Linux, any proxy or CDN in front);
- what you did, what you expected and what happened instead, step by step;
- a form definition exported as JSON, if the problem is with one form;
- the relevant log lines and browser console messages.

**Never include personal data:** no real entries, uploaded files, email addresses or IP addresses. Replace
them with made-up values before you post.

## Before you ask

- Check the documentation in [`docs/`](docs/) (the guides are written as the features arrive).
- Search the existing issues and discussions; your question may already have an answer.
